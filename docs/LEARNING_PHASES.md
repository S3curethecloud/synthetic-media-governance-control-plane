# Learning Phases

## Phase 0 — Orientation

Objective:
- Understand synthetic media governance.
- Understand why layered controls are required.

Deliverables:
- Repository walkthrough.
- Governance vocabulary.
- Threat landscape summary.

---

## Phase 1 — Threat Modeling

Objective:
- Identify protected identities and abuse scenarios.

Activities:
- Executive impersonation.
- Voice cloning fraud.
- Social engineering campaigns.
- Evidence manipulation.

Evidence:
- THREAT_MODEL.md

---

## Phase 2 — Media Intake Governance

Objective:
- Establish chain of custody.

Activities:
- Asset registration.
- Hash generation.
- Source attribution.
- Timestamp validation.

Evidence:
- Media intake records.

---

## Phase 3 — Provenance Verification

Objective:
- Validate origin claims.

Activities:
- C2PA verification.
- Content credential validation.
- Trusted source verification.

Evidence:
- Provenance reports.

## Phase 4 — Detection Layer
